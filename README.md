# Achm — тренировки, прогрессия и питание

Личное Android-приложение для силовых тренировок: планирует мезоцикл, ведёт журнал подходов,
замечает застой и подсказывает, что поменять в весах, объёме и калориях.
Работает полностью офлайн, без сервера и аккаунтов — все данные хранятся на телефоне в SQLite.

Написано на Flutter. Скачать APK: вкладка **Releases** → `trainlog-arm64.apk`.

## Что умеет

- **Планировщик.** Программа на 3–12 недель, дни недели, упражнения с перетаскиванием и копированием дня.
  Три способа задать вес: вручную, в % от расчётного максимума, линейный шаг. Автоматическая разгрузочная неделя,
  контроль лимита времени на тренировку.
- **Журнал.** Тренировка предзаполняется из плана, подход отмечается одним нажатием. Вес и повторы выбираются
  линейкой, каждый подход окрашивается статусом. Таймер отдыха с уведомлением, отметка новых рекордов.
- **Аналитика.** Расчётный 1ПМ по Эпли, объём по группам мышц на фоне целевого коридора, выполнение плана, вес тела.
- **Рекомендации и автопрогрессия.** Движок правил: две лёгкие сессии подряд (верх диапазона повторов или запас RIR) —
  прибавить вес, две частичные — снизить повторы, два провала — снизить вес, плато — сменить вариацию или добавить подход,
  общий застой — досрочная разгрузка. План меняется только после подтверждения, любое изменение можно откатить.
- **Предупреждение о перетренированности.** После закрытия недели в «Журнале» появляется карточка, если совпало
  два признака и больше: падение 1ПМ, много недоборов, скачок тоннажа, объём выше коридора, 6+ недель без разгрузки.
  Включается и выключается в «Настройках».
- **PDF-отчёт за мезоцикл для тренера.** Итоги, 1ПМ по упражнениям, нагрузка по неделям, объём по группам мышц,
  изменения плана и заметки; логотип Achm в правом верхнем углу. «План» → программа → меню → «PDF-отчёт для тренера»
  или значок PDF на экране «Аналитика».
- **Готовые программы.** Три шаблона (всё тело, верх/низ, жим/тяга/ноги) создают черновик мезоцикла в одно нажатие.
- **В зале.** Над упражнениями — ход тренировки (подходы, время, тоннаж), в карточке упражнения — результат прошлого раза,
  на экране блокировки — следующий подход и отсчёт отдыха. В меню «Ещё» — калькулятор блинов.
- **Языки и единицы.** Русский и английский интерфейс, веса в килограммах или фунтах — переключаются в «Настройках».
- **Питание.** Норма калорий и БЖУ по формуле с еженедельной адаптацией по тренду веса и рациону. Дневник,
  поиск продуктов и сканер штрихкодов (Open Food Facts), рецепты.
- **Данные.** Резервная копия в файл и восстановление, выгрузка в CSV, вход по PIN или отпечатку.

Приложение не даёт медицинских рекомендаций. Данные о продуктах — [Open Food Facts](https://openfoodfacts.org),
лицензия [ODbL](https://opendatacommons.org/licenses/odbl/1-0/). Шрифт отчёта — Roboto (Apache 2.0).

Принятые при разработке решения — в [DECISIONS.md](DECISIONS.md).

## Как получить APK без локального Android SDK

Каждый push в ветку `main` запускает workflow `.github/workflows/build-apk.yml`:
`flutter analyze` → `flutter test` → `flutter build apk --release`.

- APK лежит в артефактах запуска (вкладка **Actions** → запуск → **Artifacts**).
- Если заданы секреты подписи, APK дополнительно публикуется в **Releases** (тег `build-N`).
- Номер сборки (`versionCode`) равен номеру запуска workflow и растёт с каждой сборкой.
- Логи каждого запуска дублируются в ветку `ci-logs`.

### Секреты подписи

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**.

| Секрет | Значение |
|---|---|
| `KEYSTORE_BASE64` | keystore в base64 одной строкой: `base64 -w0 trainlog-release.jks` |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | алиас ключа (`trainlog`) |
| `KEY_PASSWORD` | пароль ключа |

Пока секретов нет, CI подписывает APK debug-ключом и пишет предупреждение: такая сборка
ставится на телефон, но не обновит и не будет обновлена release-сборкой.

## Ключ подписи

Ключ создаётся один раз и хранится вне репозитория (`*.jks` и `android/key.properties` в `.gitignore`):

```
keytool -genkeypair -v -keystore trainlog-release.jks -storetype JKS -keyalg RSA -keysize 2048 \
  -validity 10000 -alias trainlog
```

**Важно.** Android обновляет приложение поверх старого только если новый APK подписан тем же
ключом. Потеряете keystore или пароль — новую версию придётся ставить с удалением старой, то есть
с потерей данных (если нет резервной копии). Храните keystore и пароли в надёжном месте.

## Локальная сборка

Нужны Flutter (stable) и Android SDK.

```
flutter pub get
dart run build_runner build      # генерирует lib/data/database.g.dart (Drift)
flutter analyze
flutter test
flutter build apk --release      # → build/app/outputs/flutter-apk/app-release.apk (универсальный)
flutter build apk --release --split-per-abi   # отдельные APK по архитектурам, как в CI
```

Для подписи своим ключом создайте `android/key.properties`:

```
storeFile=/абсолютный/путь/trainlog-release.jks
storePassword=...
keyAlias=trainlog
keyPassword=...
```

## Установка APK на телефон

1. Скачайте `trainlog-arm64.apk` на телефон (из Releases или артефактов). `trainlog-arm32.apk` нужен только старым 32-битным устройствам.
2. Откройте файл. Android попросит разрешить установку из этого источника
   («Установка неизвестных приложений») — разрешите для браузера или файлового менеджера.
3. Обновление: установите новый APK поверх старого, данные сохранятся (при том же ключе подписи).

Минимальная версия — Android 8.0 (API 26).

## Резервная копия и восстановление

Все данные лежат только на телефоне. Без копии они пропадут при потере телефона или удалении приложения.

- **Сделать копию:** «Ещё» → «Данные и защита» → «Поделиться копией базы» (в облако, мессенджер, почту)
  или «Сохранить копию в файл» (например, в «Загрузки»). Файл — `achm-backup-ДАТА.sqlite`.
- **Восстановить:** там же → «Восстановить из копии» → выбрать файл → подтвердить. Все текущие данные
  заменяются содержимым копии. Копии старых версий приложения подходят, копии более новых — нет.
- **Напоминание:** если копии не было больше недели, на экране «Журнал» появляется карточка.
- **CSV:** журнал тренировок (строка на подход) и дневник питания (строка на запись), разделитель `;`.
- **PIN** запрашивается при запуске и не шифрует базу. Забытый PIN не восстанавливается:
  переустановите приложение и восстановите данные из копии.
